# QE Workflow Templates

Templates for Quantum ESPRESSO calculations to be used on the target HPC system.

## Structure

- `vc-relax/` – Variable-cell relaxation templates
- `scf/` – SCF calculation templates
- `phonons/` – DFPT phonon templates
- `epw/` – EPW / electron-phonon coupling templates

## Usage

These templates will be populated with specific parameters for each candidate
during the validation phase.

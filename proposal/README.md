# Scientific hosting proposal

This folder contains the final version of the scientific hosting request
sent to Professor Päivi Törmä at Aalto University.

## Files

- `hosting_proposal.pdf` – Final proposal (August 2026)

## Proposal summary

The proposal requests scientific guidance, hosting, and a possible
EuroHPC benchmarking route for the validation of GNoME-derived
superconducting candidates.

The proposal is honest about the current limitations of the MgB2
benchmark and clearly defines the scientific question and falsification
criteria.

# Pseudopotentials

This project uses pseudopotentials from the following sources:

## MgB2 benchmark
- Mg: `mg_pbe_v1.4.uspp.F.UPF` – PBE ultrasoft pseudopotential
- B: `B_pbe_v1.01.uspp.F.UPF` – PBE ultrasoft pseudopotential

## GNoME candidates
- Gd: `Gd.paw.z_18.atompaw.wentzcovitch.v1.2.upf` – PAW, from Wentzcovitch library
- Re: `Re_pbe_v1.2.uspp.F.UPF` – PBE ultrasoft
- Mo: `Mo_ONCV_PBE-1.0.oncvpsp.upf` – ONCVPSP norm-conserving
- Ru: `Ru_ONCV_PBE-1.0.oncvpsp.upf` – ONCVPSP norm-conserving
- N: `N.oncvpsp.upf` – ONCVPSP norm-conserving
